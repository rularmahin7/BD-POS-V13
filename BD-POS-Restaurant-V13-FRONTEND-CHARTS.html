KOT Printing

KOT layout follows the supplied 58mm portable-printer and 80mm restaurant-printer references: bold KOT title, table/order metadata, large item quantities, dashed separators and compact kitchen copy.

Printer Mode

Browser mode uses the normal print flow. Direct Web Serial/Web Bluetooth and Software Bridge are optional hardware/software modes; browser support and printer protocol vary by device. The bridge mode is prepared so a future desktop/native printer service can use the same KOT payload without changing the POS UI.
